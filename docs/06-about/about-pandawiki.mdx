# 关于 PandaWiki

> “思考、实践与技术沉淀。”

**PandaWiki** 是一个专注于硬件改造、嵌入式系统、Linux/WSL、Git 工作流与 AI 工具链的个人极客知识库。

---

## 🎯 建设初衷

知识库的设计核心遵循三大准则：
1. **降低内容查找成本**：采用「顶层分类 + 纵向分层 + 横向领域拆分」的清晰四层结构，符合认知习惯；
2. **降低后续维护成本**：单页单主题，建立草稿与归档缓冲区分区，避免主知识库混乱；
3. **保证知识可沉淀可扩展**：支持从原子知识点到完整项目实战、拿来即用工具库的平滑演进。

---

## 🎨 视觉设计哲学

本站视觉深度参考了 **Anthropic Claude Editorial** 极简设计系统：
* **画布质感**：采用温润的象牙白 (`#FAF9F5`) 与陶土砖红 (`#D97757`) 点缀；
* **排版体系**：古典衬线大标题 (`Newsreader`) 搭配现代无衬线正文 (`Inter`) 与极客等宽代码体 (`JetBrains Mono`)；
* **图表优先**：全面采用 **Mermaid** 矢量图表呈现架构与时序，实现深浅色模式自适应。

---

## 🛠️ 技术栈与自动化

* **静态站点生成器**：[Docusaurus v3](https://docusaurus.io/)
* **全文检索**：`@easyops-cn/docusaurus-search-local` 本地离线高亮搜索
* **持续集成与部署**：GitHub Actions 自动构建并发布至 GitHub Pages
* **开源仓库**：[github.com/Xepanda/wiki](https://github.com/Xepanda/wiki)
