# 旁路由科学上网（PassWall / OpenClash）配置与全屋终端透明代理指南

泰山派 OpenWrt 旁路由搭建完毕后，最核心的用途是实现**全屋网络透明代理**：
* 客户端（手机/电脑/电视盒子/Switch/Apple TV）**无需安装任何代理软件或客户端 App**；
* 设备只需将网络网关指向泰山派 `192.168.31.2`，即可实现国内流量直连、海外流量自动走加密节点的智能分流。

本篇记录 OpenWrt 后台科学上网插件（PassWall / OpenClash）的订阅配置，以及两种终端接入模式的详细设置。

---

## 1. OpenWrt 后台订阅节点导入（以 PassWall 为例）

1. 浏览器打开 `http://192.168.31.2`（默认用户名 `root`，默认密码 `password` 或空）。
2. 点击顶部菜单 **服务 (Services) ➔ PassWall**：


### 1.1 节点订阅与基本设置
* **节点订阅**：点击“节点订阅”标签 ➔ 添加订阅链接 ➔ 点击“保存并应用” ➔ 点击“手动更新订阅”；
* **基本设置**：
  * **主开关**：勾选启用；
  * **TCP 节点**：选择目标高速节点（如香港/新加坡/日本节点，或自动选择最低延迟节点）；
  * **UDP 节点**：可选择与 TCP 相同节点（支持游戏/语音加速）；
  * **运行模式**：保持默认 **“中国列表以外 (绕过大陆 IP)”**；
  * **DNS 过滤模式**：选择 `ChinaDNS-NG` 或 `UDP 转发`，防止 DNS 污染。
* 点击右下角 **“保存并应用”**。

## 2. 终端设备接入旁路由的两种模式

### 模式 A：指定单机接入模式（强烈推荐 ⭐⭐⭐⭐⭐，零风险）

只让需要翻墙的设备走泰山派旁路由，家里老人、小孩的手机或智能家居依旧走主路由器，互不干扰，即使泰山派关机重启全家也不会断网。

#### 📱 手机 / 平板设置（以 iOS / Android 为例）
1. 连接家庭 Wi-Fi ➔ 点击 Wi-Fi 名称右侧的 ℹ️（详情）；
2. 将 **IP 获取方式 (IPv4 设置)** 由 `自动 (DHCP)` 改为 **`手动 (静态 / Static)`**：
   * **IP 地址**：`192.168.31.188`（填一个未被占用的 IP，例如 192.168.31.100~200 之间）；
   * **子网掩码**：`255.255.255.0`；
   * **路由器 (网关 / Gateway)**：填写 **`192.168.31.2`**（指向泰山派）；
   * **DNS**：填写 **`192.168.31.2`**；
3. 保存后无需重连，打开浏览器直接访问 `google.com` 或 `youtube.com` 即秒级打开！

#### 💻 Windows / macOS 电脑设置
1. 打开网络适配器设置 ➔ 选择当前网络 ➔ 编辑 IPv4；
2. 改为手动输入：
   * **IP 地址**：`192.168.31.150`
   * **子网掩码**：`255.255.255.0`
   * **默认网关**：`192.168.31.2`
   * **首选 DNS**：`192.168.31.2`

---

### 模式 B：全屋自动托管模式（全家无感透明代理）

适合希望全屋所有设备连上 Wi-Fi 自动拥有科学上网与去广告功能的用户：

1. 打开浏览器登录家里的小米主路由器后台（`http://192.168.31.1`）；
2. 进入 **常用设置 ➔ 局域网设置 (DHCP 服务)**：
   * **默认网关**：修改为 **`192.168.31.2`**；
   * **DNS 服务器**：修改为 **`192.168.31.2`**；
3. 保存并应用。
4. **效果**：全屋所有连接 Wi-Fi 的手机、平板、Apple TV、智能电视全部自动经由泰山派旁路由进行流控与节点加速。
