# Docker 常用命令

## 容器生命周期

| 命令 | 说明 |
|------|------|
| `docker ps` | 查看运行中的容器 |
| `docker ps -a` | 查看所有容器 |
| `docker start <容器>` | 启动已停止的容器 |
| `docker stop <容器>` | 停止运行中的容器 |
| `docker restart <容器>` | 重启容器 |
| `docker rm <容器>` | 删除容器 |
| `docker logs <容器>` | 查看容器日志 |
| `docker logs -f <容器>` | 实时跟踪日志 |
| `docker exec -it <容器> bash` | 进入容器 shell |

## Compose 管理

```bash
# 在 docker-compose.yml 所在目录执行
docker compose up -d          # 启动所有服务
docker compose down           # 停止并删除所有服务
docker compose restart        # 重启所有服务
docker compose logs -f        # 查看所有日志
docker compose ps             # 查看服务状态
docker compose build --no-cache  # 强制重建镜像
```

## 镜像管理

| 命令 | 说明 |
|------|------|
| `docker images` | 列出本地镜像 |
| `docker pull <镜像>` | 拉取镜像 |
| `docker rmi <镜像>` | 删除镜像 |
| `docker build -t name:tag .` | 构建镜像 |
| `docker tag src dest` | 打标签 |

## 清理空间

```bash
docker system prune -a   # 删除所有未使用的镜像/容器/网络/缓存
docker volume prune      # 删除未使用的卷
docker builder prune     # 清理构建缓存
```

注意：`prune` 不可逆，确认清楚再执行。

## 端口与网络

```bash
# 查看端口映射
docker port <容器>

# 查看网络
docker network ls

# 查看容器 IP
docker inspect <容器> | grep IPAddress
```

## 常用组合示例

### 查看所有容器（含已停止）并清理

```bash
docker ps -a
docker container prune   # 删除所有已停止的容器
```

### 进入 Postgres 容器

```bash
docker exec -it <postgres容器名> psql -U <用户名>
```

### 复制文件进出容器

```bash
docker cp <本地文件> <容器>:/path/
docker cp <容器>:/path/file ./
```

## Docker Compose 文件示例

```yaml
services:
  app:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - ./html:/usr/share/nginx/html
    restart: unless-stopped
```
