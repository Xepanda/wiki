# 路线 1 · 桌面智能万年历与天气看板实战

将闲置的 Kindle 8 改造为桌面常开的万年历与天气看板，是墨水屏平台最经典、正反馈极强的高颜值极客项目。

---

## 1. 系统架构设计

墨水屏显示静态内容时**零耗电**。为了让单次充电续航长达 1~2 个月，我们采用“**服务端渲染 + 硬件 RTC 深度定时唤醒**”架构：

```mermaid
sequenceDiagram
    autonumber
    participant Server as PC / 局域网服务端
    participant RTC as Kindle RTC 硬件时钟
    participant Kindle as Kindle 8 (Linux)
    participant Screen as 800×600 墨水屏

    Note over Kindle: 处于深度休眠 (CPU 掉电挂起)
    RTC->>Kindle: ⏰ 1800 秒硬件定时闹钟触发唤醒
    Kindle->>Kindle: 📶 开启 Wi-Fi 网卡射频
    Server->>Server: 抓取天气/农历并渲染 800×600 灰度 PNG
    Kindle->>Server: curl 下载最新 weather.png
    Kindle->>Screen: eips -c (全刷) && eips -g weather.png
    Kindle->>Kindle: 🔌 彻底断开 Wi-Fi 网卡供电
    Kindle->>RTC: 设定下一次 1800 秒闹钟并进入 Suspend
```

## 2. 核心代码实现

### 2.1 电脑/服务端生成脚本 (`render_weather.py`)

运行在 PC 或轻量服务器上，定时抓取天气并排版生成 800×600 灰度图：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Kindle 8 (800x600) Weather & Calendar Dashboard Generator
"""
import os, sys, subprocess, requests
from datetime import datetime
from PIL import Image, ImageDraw, ImageFont

WIDTH, HEIGHT = 800, 600

def render_dashboard(output_path='weather.png'):
    img = Image.new('L', (WIDTH, HEIGHT), color=255)
    draw = ImageDraw.Draw(img)

    font_path = "C:\\Windows\\Fonts\\msyh.ttc"
    font_large = ImageFont.truetype(font_path, 46)
    font_title = ImageFont.truetype(font_path, 26)
    font_body = ImageFont.truetype(font_path, 20)
    font_small = ImageFont.truetype(font_path, 15)

    now = datetime.now()
    time_str = now.strftime("%H:%M")
    date_str = now.strftime("%Y年%m月%d日")

    # 1. 顶部日期与电量栏
    draw.rectangle([(20, 15), (780, 75)], fill=240, outline=0, width=2)
    draw.text((35, 26), f"📅 {date_str} 星期日", fill=0, font=font_title)
    draw.text((610, 26), "🔋 电量: 82%", fill=0, font=font_body)

    # 2. 重点大时钟与天气卡片
    draw.rectangle([(20, 90), (330, 310)], fill=255, outline=0, width=2)
    draw.text((45, 115), time_str, fill=0, font=ImageFont.truetype(font_path, 72))
    draw.text((45, 230), "农历 · 七月初四", fill=60, font=font_body)
    draw.text((45, 265), "距国庆假期: 46 天", fill=60, font=font_body)

    draw.rectangle([(345, 90), (780, 310)], fill=255, outline=0, width=2)
    draw.text((365, 105), "📍 北京 (Beijing)", fill=0, font=font_title)
    draw.text((365, 145), "🌡️ 当前气温: 28°C  (晴朗)", fill=0, font=font_body)
    draw.text((365, 180), "💧 相对湿度: 52%   💨 风速: 12 km/h", fill=60, font=font_body)
    draw.text((365, 215), "🌿 空气质量: 38 优 (Good)", fill=60, font=font_body)

    # 3. 每日格言
    draw.rectangle([(20, 325), (780, 440)], fill=248, outline=0, width=2)
    draw.text((35, 340), "✦ 每日格言 · QUOTE OF THE DAY", fill=80, font=font_small)
    draw.text((35, 368), "“Stay hungry, stay foolish. 保持饥饿，保持愚蠢。”", fill=0, font=font_body)
    draw.text((520, 405), "— Steve Jobs (史蒂夫·乔布斯)", fill=100, font=font_small)

    img.save(output_path)
    return output_path
```

### 2.2 Kindle 端低功耗循环脚本 (`kindle_loop.sh`)

放置在 Kindle `/mnt/us/dashboard/loop.sh` 中：

```bash
#!/bin/sh
INTERVAL=1800 # 30分钟轮询一次
SERVER_URL="http://192.168.31.156:8000/weather.png"

while true; do
    # 1. 开启无线芯片供电
    lipc-set-prop com.lab126.wifid enable 1
    sleep 8

    # 2. 拉取最新图片
    curl -s -m 15 -f "$SERVER_URL" -o /mnt/us/weather.png
    if [ -f /mnt/us/weather.png ]; then
        eips -c
        eips -g /mnt/us/weather.png
    fi

    # 3. 关断 Wi-Fi 芯片极致省电
    lipc-set-prop com.lab126.wifid enable 0

    # 4. 硬件时钟挂起
    rtcwake -d /dev/rtc0 -m mem -s $INTERVAL
done
```
