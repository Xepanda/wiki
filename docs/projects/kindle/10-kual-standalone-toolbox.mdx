# 路线 5 · Kindle 本地脱机 KUAL 极客工具箱实战

真正的极客设备必须具备 **100% 本地脱机独立运行** 的能力。我们将所有开发的功能封装成标准的 **KUAL 图形插件**，无需打开电脑，手指在 Kindle 屏幕上点击即可直接调用！

---

## 1. KUAL 插件架构与目录规范

KUAL 插件遵循标准的 JSON 菜单与 Shell 动作解耦模型，统一存放于 `/mnt/us/extensions/`：

```mermaid
graph TD
    A["📱 Kindle 屏幕点击 KUAL 图标"] --> B["📂 /mnt/us/extensions/geek_toolbox/"]
    B --> C["📄 menu.json (图形化菜单与按钮配置)"]
    C --> D1["📟 bin/weather_refresh.sh (天气看板)"]

    C --> D3["📁 bin/ftp_start.sh (开启 FTP 2121)"]
    C --> D4["🔒 bin/nosleep.sh (锁定常亮)"]
    C --> D5["📊 bin/system_status.sh (硬件状态)"]

    style B fill:#f4f2ec,stroke:#d97757,stroke-width:2px
    style C fill:#f4f2ec,stroke:#d97757,stroke-width:1.5px
```

## 3. 脱机使用体验

1. 打开 Kindle 桌面上的 **KUAL 图标**；
2. 点击 **【极客工具箱 (Geek Toolbox)】** 进入二级菜单；
3. 直接手指点选功能，Kindle 会在后台执行对应的 Shell 脚本并在屏幕上即时反馈，完全脱离对 PC 电脑的依赖！
