# Home Assistant 智能家居中枢部署：打通米家、涂鸦/鹊起生态与小爱音箱语音控制实战

在泰山派 All-in-One 架构中，**Home Assistant (HA)** 扮演着“全屋智能家庭中枢大脑”的核心角色。

本文记录在泰山派 RK3566 开发板上部署 Home Assistant Core、预置 HACS、Xiaomi Miot Auto（米家核心插件）与 LocalTuya（涂鸦/鹊起本地直连插件），打破品牌壁垒，实现**使用小米小爱音箱 Play 语音直接调度全屋涂鸦/鹊起智能设备**的完整工程落地实战。

## 2. 泰山派容器化极速部署实操

### 2.1 目录规划与权限准备
```bash
mkdir -p /opt/all-in-one/homeassistant/config/custom_components
```

### 2.2 启动 Home Assistant 核心容器
采用 `--net=host` 模式启动，确保局域网内的 mDNS、SSDP、小米 miio 广播协议能够原生直连穿透：

```bash
docker run -d \
  --name homeassistant \
  --restart=always \
  --privileged \
  --net=host \
  -v /opt/all-in-one/homeassistant/config:/config \
  -v /etc/localtime:/etc/localtime:ro \
  -e TZ=Asia/Shanghai \
  homeassistant/home-assistant:stable
```

## 3. 三大核心插件预置与功能解析

已预置到 `/config/custom_components/` 的核心组件矩阵：

| 插件名称 | 目录路径 | 核心能力与解决的痛点 |
| :--- | :--- | :--- |
| **`xiaomi_miot`** | `custom_components/xiaomi_miot` | **国内米家生态神级插件（巴哥开发）**。支持全量导入小米设备、监听小爱音箱对话事件（`xiaomi_miot.xiaoai_conversation`）、实现小爱 TTS 自定义语音播报与虚拟设备桥接。 |
| **`localtuya`** | `custom_components/localtuya` | **涂鸦/鹊起本地直连插件**。基于 LocalKey 走局域网 TCP 6668/6667 通信，断网可用、0 云端依赖、响应时延仅 20~50ms。 |
| **`hacs`** | `custom_components/hacs` | **Home Assistant 社区商店**。方便后续一键安装更多主题、海报墙卡片与第三方集成。 |

## 4. 设备接入与配置指引

### 4.1 访问控制台与初始化账号
* **访问入口**：在浏览器打开 👉 **`http://nas.local:8123`**（或 `http://192.168.31.32:8123`）；
* **创建管理员**：输入你的自定义用户名与密码，点击【创建账户】并选择家庭位置（系统时区已自动同步为 `Asia/Shanghai`）。

### 4.2 接入小米米家设备与小爱音箱 Play
1. 在 HA 左侧菜单点击 **【设置 (Settings)】 $\rightarrow$ 【设备与服务 (Devices & Services)】 $\rightarrow$ 【添加集成 (Add Integration)】**；
2. 搜索并选择 **`Xiaomi Miot Auto`**；
3. 选择 **【账号集成 (Cloud)】**，输入你的米家小米账号与密码：
   * 筛选模式选择“包含所有设备”；
   * 点击提交后，全屋所有米家插座、开关、传感器以及 **小爱音箱 Play** 将全量自动导入 HA！

### 4.3 接入涂鸦智能与鹊起智能设备
“鹊起智能”属于涂鸦（Tuya）智能硬件生态，接入方式完全统一：
1. **云端模式（最简便）**：
   * 在【添加集成】中搜索 **`Tuya`**；
   * 打开手机上的【涂鸦智能】或【智能生活 (Smart Life)】App 扫码，全量鹊起与涂鸦设备自动同步进 HA。
2. **本地直连模式（超低延迟·推荐）**：
   * 在【添加集成】中搜索 **`LocalTuya`**；
   * 输入设备的 IP 地址与 `Local Key`，实现纯局域网免云控秒级响应。

## 5. 小爱音箱跨生态语音控制与实战调优

### 5.1 涂鸦 OEM 贴牌硬件（如鹊起智能）救砖与公版迁移秘籍
部分涂鸦 OEM 设备（如鹊起智能万能遥控器）由于出厂固件注入了专属 ProductKey，导致在公版【智能生活】App 中无法“自动搜索”被发现，且官方扫码报错 `E0020003`。

**解决方案（底层的 AP 热点慢闪救砖法）**：
1. **进入 AP 慢闪模式**：长按设备按键 5 秒进入快闪模式，**松开后紧接着再次长按 5 秒**，指示灯变为约 2~3 秒闪烁一次的慢闪状态；
2. **热点配网**：打开【智能生活】App $\rightarrow$ 【添加设备】 $\rightarrow$ 选择【电工/万能遥控器】 $\rightarrow$ 右上角切换为 **【AP 模式】**；
3. **连接热点**：手机连接设备发出的 `SmartLife-xxxx` 开放 Wi-Fi，手机 App 会直接绕过 OEM 品牌白名单限制，将其强制迁移并绑定到公版【智能生活】账号下。

---

### 5.2 毫秒级极速响应调优（告别 3 秒轮询延迟）

* **传统被动轮询模式（较慢，约 2~4 秒）**：
  小爱音箱识别完成后将对话保存至小米云端，HA 定期轮询云端对话日志，存在轮询周期等待。
* **米家主动推送场景（极速秒开，< 0.3 秒 · 强烈推荐）**：
  1. 在手机【米家 App】中新建手动执行场景：名称设为 `打开工作台`（动作设为小爱播报文本或执行空动作）；
  2. 当你对小爱说“打开工作台”时，米家云端在 0.1 秒内通过 Event Webhook 主动向泰山派 HA 推送事件；
  3. HA 收到推送后在 10ms 内触发涂鸦插座或万能遥控器开空调，整体延迟降至 **0.2~0.3 秒**，实现如丝般顺滑的秒开体验。

### 5.3 泰山派生产环境自动化规则配置

在泰山派 `/opt/all-in-one/homeassistant/config/automations.yaml` 中的生产级配置：

```yaml
- id: 'xiaoai_turn_on_workbench_socket'
  alias: '小爱音箱语音联动：打开工作台插座'
  description: '当小爱音箱触发 打开工作台 时，开启工作台智能插座'
  trigger:
    - platform: state
      entity_id: sensor.xiaomi_l05b_b558_conversation
    - platform: event
      event_type: xiaomi_miot.xiaoai_conversation
  condition:
    - condition: template
      value_template: >-
        {{
          ('打开工作台' in (trigger.to_state.state | default(''))) or
          ('开工作台' in (trigger.to_state.state | default(''))) or
          ('打开插座' in (trigger.to_state.state | default(''))) or
          ('打开工作台' in (trigger.event.data.query | default('')))
        }}
  action:
    - service: switch.turn_on
      target:
        entity_id: switch.wifizhi_neng_cha_zuo_mc007_socket_1
    - service: text.set_value
      target:
        entity_id: text.xiaomi_l05b_b558_play_text
      data:
        value: "好的，工作台已打开"
  mode: restart

- id: 'xiaoai_turn_on_haier_ac'
  alias: '小爱音箱语音联动：打开海尔空调'
  description: '当小爱音箱触发 打开空调 时，通过涂鸦万能遥控器发射红外码'
  trigger:
    - platform: state
      entity_id: sensor.xiaomi_l05b_b558_conversation
    - platform: event
      event_type: xiaomi_miot.xiaoai_conversation
  condition:
    - condition: template
      value_template: >-
        {{
          ('打开空调' in (trigger.to_state.state | default(''))) or
          ('开空调' in (trigger.to_state.state | default(''))) or
          ('打开空调' in (trigger.event.data.query | default('')))
        }}
  action:
    - service: scene.turn_on
      target:
        entity_id: scene.da_kai_kong_diao
    - service: text.set_value
      target:
        entity_id: text.xiaomi_l05b_b558_play_text
```
