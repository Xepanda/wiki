# 01. 硬件架构、引脚映射与双控制器规范

在物联网边缘设备与桌面显示终端中，**电子墨水屏（E-Paper Display, EPD）** 凭借双稳态（Bistable）超低功耗、全反射式环境光阅读体验以及高对比度纸质质感，成为了智能仪表、电子相框、信息看板的理想载体。

本项目基于 **涂鸦 TuyaOpen 开源物联网框架** 与 **T5-Core（博通集成 BK7258 双核 ARM Cortex-M33）** 开发板，构建了一套能够自适应驱动 **4.2 英寸黑白红三色屏（SSD1683 / DEPG0420）** 与 **4.2 英寸黑白黄红四色屏（GDEM042F86 / SSD2683）** 的通用嵌入式渲染固件。

---

## 一、 硬件规格与控制器对比

本项目兼容市面上两款最主流的 4.2 英寸电子墨水屏。两款屏幕物理尺寸和引脚完全一致，但内部驱动 IC 与显存编码存在显著差异：

| 硬件特性 | 三色墨水屏 (Tri-Color) | 四色墨水屏 (4-Color Spectra 3100) |
| :--- | :--- | :--- |
| **典型面板型号** | **DEPG0420** / **GDEW042Z15** | **GDEM042F86** (Good Display) |
| **主控芯片** | **SSD1683** / **UC8176** | **SSD2683** (Solomon Systech) |
| **显示色彩** | **纯黑、纯白、赤红 (3 色)** | **纯黑、纯白、金黄、赤红 (4 色)** |
| **物理分辨率** | **400 × 300** 像素 (4:3) | **400 × 300** 像素 (4:3) |
| **显存架构** | **双平面 1-bit** (15KB 黑白 + 15KB 红) | **单平面 2-bit** (30KB，4 像素/字节) |
| **BUSY 引脚极性** | **高电平 (1) = Busy (正在刷新)**<br/>低电平 (0) = Idle (空闲) | **低电平 (0) = Busy (正在刷新)**<br/>高电平 (1) = Idle (空闲) |
| **刷新耗时** | 约 18 ~ 20 秒 (全屏波形) | **标准模式 ~18s / 极速模式 ~12s** |
| **工作电压** | 3.3V (VCI: 2.3V ~ 3.6V) | 3.3V (VCI: 2.3V ~ 3.6V) |

## 二、 T5-Core 开发板引脚物理接线

两款墨水屏转接板均引出标准的 8 针 2.54mm 排针，与 T5-Core 开发板通过杜邦线连接，**引脚完全通用**：

| 墨水屏引脚 | 信号定义 | T5-Core GPIO | 方向 | 硬件功能说明 |
| :--- | :--- | :--- | :--- | :--- |
| **VCC** | 3.3V | **3.3V** | 电源输入 | 模块供电（2.3V ~ 3.6V，推荐 3.3V） |
| **GND** | GND | **GND** | 电源地 | 系统共地 |
| **DIN** | MOSI / SDA | **GPIO 4** | MCU 输出 | 4 线 SPI 主机数据发送线 |
| **CLK** | SCK / SCL | **GPIO 2** | MCU 输出 | 4 线 SPI 时钟线（SPI Mode 0） |
| **CS** | CS# | **GPIO 3** | MCU 输出 | 片选引脚（低电平选中有效） |
| **DC** | D/C# | **GPIO 6** | MCU 输出 | 数据/命令控制（高电平=Data，低电平=Command） |
| **RST** | RES# | **GPIO 7** | MCU 输出 | 硬件复位引脚（低电平复位脉冲 20~40ms） |
| **BUSY** | BUSY | **GPIO 8** | MCU 输入 | 忙状态指示引脚（用于硬件波形握手） |

```
  +-------------------+               +----------------------+
  |  T5-Core (BK7258) |               |  4.2" E-Paper Module |
  |                   |               |                      |
  |             3.3V  +--------------->  VCC                 |
  |              GND  +--------------->  GND                 |
  |           GPIO 4  +---[ MOSI ]---->  DIN                 |
  |           GPIO 2  +---[ SCK  ]---->  CLK                 |
  |           GPIO 3  +---[ CS#  ]---->  CS                  |
  |           GPIO 6  +---[ D/C# ]---->  DC                  |
  |           GPIO 7  +---[ RES# ]---->  RST                 |
  |           GPIO 8  <---[ BUSY ]----+  BUSY                |
  +-------------------+               +----------------------+
```

## 三、 SPI 接口通信协议与时序

电子墨水屏内部控制器采用 **4-Wire SPI (Mode 0)** 协议进行数据与指令交换：
- **CPOL = 0**：时钟空闲时为低电平；
- **CPHA = 0**：在时钟上升沿（Rising Edge）采样数据，在时钟下降沿移位；
- **最大时钟速率**：控制器支持最高 **10 MHz** SPI 时钟。

### 1. 指令写入时序（Command Write）
1. 拉低 `DC`（`GPIO 6 = 0`）；
2. 拉低 `CS`（`GPIO 3 = 0`）；
3. 通过 `MOSI` 发送 8-bit 指令字节；
4. 拉高 `CS`（`GPIO 3 = 1`）。

### 2. 数据写入时序（Data Write）
1. 拉高 `DC`（`GPIO 6 = 1`）；
2. 拉低 `CS`（`GPIO 3 = 0`）；
3. 通过 `MOSI` 发送 8-bit 数据字节或批量传输图像缓冲区；
4. 拉高 `CS`（`GPIO 3 = 1`）。

## 四、 双控制器驱动协议与初始化流程

### 1. 三色控制器（SSD1683 / DEPG0420）
三色墨水屏显存分为两个独立的 15KB 平面：
- **黑白平面（RAM 0x24）**：$400 \times 300 / 8 = 15,000$ 字节，`0` 表示黑色，`1` 表示白色；
- **红色平面（RAM 0x26）**：$400 \times 300 / 8 = 15,000$ 字节，`1` 表示红色，`0` 表示非红（透明）；
- **刷新指令**：写入 `0x22, 0xF7`，再写入 `0x20` 启动高压物理波形；
- **BUSY 等待**：等待 `BUSY` 变低（`0`）表示刷新完成。

### 2. 四色控制器（SSD2683 / GDEM042F86）
四色墨水屏显存采用 **2-bit Packed** 格式：
- **单平面 2-bit（RAM 0x10）**：每字节容纳 4 个像素，总计 **30,000** 字节；
- **像素编码**：`00b` = 纯黑, `01b` = 纯白, `10b` = 金黄, `11b` = 赤红；
- **刷新指令**：写入 `0x12, 0x00` 启动物理波形；
- **BUSY 等待**：芯片先拉低 `BUSY=0` 输出波形，等待 `BUSY` 恢复高电平（`1`）表示刷新完成。

## 五、 硬件诊断与引脚自检工具

固件内置了硬件自检 CLI 命令，用于在上板调试时排查接触不良或虚焊问题：

```bash
# 1. 打印引脚映射并执行 30KB SPI 传输速率测试
epd_test

# 2. 以 1Hz 频率交替输出 3.3V 与 0V（万用表测通断）
epd_pins 5
```
