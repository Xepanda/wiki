# Kindle 8 越狱、OTA阻断与 KUAL 系统部署

本篇记录了将一台吃灰的 **Kindle 8th Gen (KT3 / 8代入门版)** 彻底解锁为极客墨水屏嵌入式 Linux 终端的全流程实战经验。

---

## 1. 越狱状态与版本判定

Kindle 8 属于第 8 代入门级电子书阅读器（代号 `KT3`），采用 ARMv7 架构的恩智浦单核 CPU，运行基于 Linux 3.10 内核定制的精简系统。

### 1.1 越狱成功的标志
* **开机提示**：重启 Kindle 开机底部若出现 `**** JAILBREAK ****` 或 `Hush, little baby...` 字符串，代表越狱注入器（Jailbreak payload）已成功驻留；
* **签名密钥**：系统需要刷入 **MKK (MobileRead Kindle Booklet)** 签名热修复补丁，使 Kindle 允许执行自定义自制应用（Booklet/Kindlet）。

## 2. 永久阻断 OTA 自动升级（双重防御）

如果连接 Wi-Fi 期间 Kindle 被亚马逊推送 OTA 固件更新，可能会导致越狱失效并封堵漏洞。必须实施**双重防御策略**。

### 防御层 1：文件系统级文件夹占位锁
在 Kindle 存储根目录下创建同名不可写入的文件夹，破坏亚马逊下载升级临时文件的机制：

```powershell
# 在 Kindle 挂载盘（如 E 盘）根目录执行
mkdir E:\update.bin.tmp.partial
Set-ItemProperty -Path "E:\update.bin.tmp.partial" -Name Attributes -Value ([System.IO.FileAttributes]::ReadOnly -bor [System.IO.FileAttributes]::Directory)
```

### 防御层 2：系统底层守护进程屏蔽
通过 SSH 挂载 rootfs 为读写并重命名 OTA 守护进程：
```bash
mntroot rw
[ -f /usr/sbin/otad ] && mv /usr/sbin/otad /usr/sbin/otad.bak
[ -f /usr/sbin/otav3 ] && mv /usr/sbin/otav3 /usr/sbin/otav3.bak
mntroot ro
```

## 3. KUAL 启动器安装（避坑 5.14+ 白屏问题）

KUAL (Kindle Unified Application Launcher) 是运行各种极客插件（如 USBNetwork、KOReader、Helper+）的核心图形入口。

### ⚠️ 避坑重点：高版本固件白屏
* **旧版 Kindlet (.azw2)**：基于 Java Kindlet 技术，在 5.14 及以上固件中会被亚马逊框架彻底禁用，点击会发生**白屏卡死**；
* **正确解决方案**：使用适配高版本的 **KUAL Booklet (Coplate 维护版)**。

### 安装步骤：
1. **部署 MRPI 安装器**：
   * 下载 `kual-mrinstaller-1.7.N`，将 `extensions` 文件夹解压至 Kindle 根目录；
   * 在 Kindle 根目录新建 `mrpackages` 文件夹。
2. **放入刷机包**：
   * 将 `Update_KUALBooklet_c6ac782_install.bin` 放入 `E:\mrpackages\`。
3. **触发刷入**：
   * 在 Kindle 顶部搜索框输入：
     ```text
     ;log mrpi
     ```
   * Kindle 会自动调用 MRPI 底层安装引擎，屏幕闪烁后完成 KUAL Booklet 刷入。
   * 桌面会出现 **KUAL 图标**，点击即可秒开插件菜单！
