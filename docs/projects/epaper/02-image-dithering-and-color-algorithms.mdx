# 02. 电子墨水屏图像算法：边缘保护、16阶灰度与Kindle级光影

电子墨水屏（E-Paper）在微观上由数百万个充满透明流体的微胶囊组成。标准 3 色与 4 色墨水屏**完全不具备原生硬件灰阶调光能力**，每个物理像素只能呈现固定的离散原色（黑、白、红，或黑、白、黄、红）。

如果直接对连续色调图像进行最近邻阈值量化（Nearest Color Mapping），会导致暗部死黑、高光惨白、渐变断层严重（Banding）。为了在 1-bit 和 2-bit 的极度受限色阶下重现照片级的层次感与插画级的线条锐度，本项目设计并实现了 **4 套专为电子墨水屏定制的高阶图像处理管线**。

## 二、 算法原理与数学模型深度剖析

### 1. 方案 1：边缘保护 + 阿特金森抖动（Edge-Preserved Atkinson）

传统 Floyd-Steinberg 算法会将高对比度边缘的误差强行扩散到邻域，导致黑白线条两侧出现大量“污迹状”杂散点。

**算法改进管线**：
1. **Sobel 轮廓提取**：
   计算水平与垂直梯度：
   ```text
   Gx = [[-1, 0, +1], [-2, 0, +2], [-1, 0, +1]] * I
   Gy = [[-1, -2, -1], [ 0,  0,  0], [+1, +2, +1]] * I
   G  = sqrt(Gx^2 + Gy^2)
   ```
2. **骨架硬锁定（Edge Locking）**：
   对梯度 `G > T_edge` 的像素直接强制锁定为纯黑，不参与误差扩散，切断线条模糊；
3. **阿特金森衰减扩散（Atkinson Dithering）**：
   阿特金森算法仅扩散量化误差的 `6/8 = 75%`（丢弃剩余 25%），扩散核权重如下：
   ```text
   Kernel = 1/8 * [
       [  *, 1, 1 ],
       [ 1, 1, 1, 0 ],
       [ 0, 1, 0, 0 ]
   ]
   ```
   这使得白色与红色纯色背景中的噪点迅速衰减归零，保持背景极其纯净。

---

### 2. 方案 3：16 阶灰度空间网点抖动（16-Level Bayer Halftoning）

经典报刊印刷业（Halftoning）通过控制微小油墨网点的大小和疏密，让人眼在视网膜上自动融合出连续灰度。

**算法实现**：
1. **标准 4x4 拜耳矩阵（Bayer Matrix）**：
   ```text
   M = 1/16 * [
       [  0,  8,  2, 10 ],
       [ 12,  4, 14,  6 ],
       [  3, 11,  1,  9 ],
       [ 15,  7, 13,  5 ]
   ]
   ```
2. **灰度空间映射**：
   输入像素灰度 `V in [0, 255]` 先被均匀量化为 16 个级别：
   `level = floor(V * 15 / 255)`
3. **空间点阵调制**：
   若 `(V % 16) / 16 > M[y % 4][x % 4]`，则像素点亮，否则置黑。由此在微观上生成极具工业复古美感的均匀印刷点阵。

### 3. 方案 4：Kindle 级照片高动态光影（Gamma 1.45 & Serpentine）

电子墨水屏由于反射率限制（底色为浅灰色而非纯白），线性量化会导致暗部大面积死黑。

**算法改进管线**：
1. **Gamma 1.45 暗部反射率校正**：
   ```text
   I_corrected = 255 * ((I / 255) ^ (1 / 1.45))
   ```
   将暗部细节大幅拉伸提亮，使阴影中的毛发和景深层次重现；
2. **反遮罩高频锐化（Unsharp Masking, USM）**：
   ```text
   I_sharp = I + 1.2 * (I - GaussianBlur(I, sigma=1.0))
   ```
   增强眼睛高光、动物胡须等高频边缘的反差；
3. **蛇形双向误差扩散（Serpentine Traversal）**：
   偶数行从左向右（`L -> R`）扩散，奇数行从右向左（`R -> L`）反向扩散，彻底消除了单向扫描带来的对角线斜纹伪影（Worm Artifacts）。

## 三、 四色墨水屏（CIE Lab 色彩聚类与量化）

四色墨水屏包含**黑、白、黄、红**四种物理色素。RGB 色彩空间的欧氏距离与人眼主观色彩感知存在显著偏差（例如黄色与白色在 RGB 下数值接近，但视觉上黄色明度极高且带有强烈的色相）。

本项目采用 **CIE L\*a\*b\* 色彩空间** 计算色差 Delta E：

```text
Delta E = sqrt((L1 - L2)^2 + (a1 - a2)^2 + (b1 - b2)^2)
```

针对四色物理色板进行自适应聚类：
- **纯黑 (`00b`)**：`L* = 0, a* = 0, b* = 0`
- **纯白 (`01b`)**：`L* = 100, a* = 0, b* = 0`
- **金黄 (`10b`)**：`L* = 85, a* = 5, b* = 95`
- **赤红 (`11b`)**：`L* = 50, a* = 70, b* = 50`

通过引入黄色与红色的饱和度加权阈值，使金黄流光（武士刀刃与战甲锁边）与赤红落日被精准分离并映射到专属的物理粒子微胶囊中。
